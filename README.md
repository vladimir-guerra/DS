# ACTIVIDAD PRÁCTICA
Diseñen una aplicación sencilla para una empresa que permita registrar productos.
La aplicación deberá permitir:

- Ingresar código.
- Ingresar nombre.
- Ingresar precio.
- Ingresar cantidad.
- Guardar el producto.
- Consultar los productos registrados.
- Modificar un producto.
- Eliminar un producto.

El programa deberá utilizar algún mecanismo de persistencia para que los productos continúen almacenados después de cerrar y volver a abrir la aplicación.
